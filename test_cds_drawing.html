CDS Drawing Test Instructions

How to Test

  1. Open index.html in your browser (the main Sealion viewer)
  2. Load an alignment file (any FASTA or JSON alignment)
  3. Click on "Add reference genome" in the toolbar
  4. Select the NC_002549_EBOV_1976.json file
  5. The reference genome will be automatically selected and displayed in the consensus canvas
  6. Look at the overview canvas (the mini-map at the top)
  7. You should see:
    • Colored rectangles in 3 rows representing the CDS features
    • Gene labels (e.g., "NP", "VP35", "GP") displayed on each CDS bar
    • Frame 1 (top row): Blue rectangles
    • Frame 2 (middle row): Red rectangles
    • Frame 3 (bottom row): Green rectangles
  8. Hover over any CDS bar to see a tooltip with:
    • Gene name (bold)
    • Product description
    • Genomic coordinates
    • Function (if available)
  9. Double-click on any CDS bar to select all columns in that CDS range:
    • All columns within the CDS coordinates will be selected
    • For CDS with join() coordinates (like GP), all segments are selected
    • Selected columns are highlighted in the main sequence view
    • Check the browser console for selection info
  10. CDS display persistence:
    • Once a reference genome is loaded, its CDS structure stays visible in the overview canvas
    • Switching to "Consensus" or "Selected sequence" keeps showing the CDS structure
    • CDS display only changes when you explicitly select a different reference genome
    • This allows you to see the genome structure while comparing different sequences

CDS Reading Frame Colors

Frame 1: Blue - CDS starting at positions 1, 4, 7, 10, ... (start % 3 == 1)
Frame 2: Red - CDS starting at positions 2, 5, 8, 11, ... (start % 3 == 2)
Frame 3: Green - CDS starting at positions 3, 6, 9, 12, ... (start % 3 == 0)

Expected CDS Features in NC_002549_EBOV_1976.json

  • NP (nucleoprotein): 470..2689
  • VP35 (polymerase complex protein): 3129..4151
  • VP40 (matrix protein): 4479..5459
  • GP (spike glycoprotein): join(6039..6923,6923..8068)
  • VP30 (minor nucleoprotein): 8509..9375
  • VP24 (membrane-associated protein): 10345..11100
  • L (RNA-dependent RNA polymerase): 11581..18219
