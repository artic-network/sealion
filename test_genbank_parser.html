GenBank File Parser Utility

Purpose: This utility parses GenBank format files (.gb) and converts them to the reference genome JSON format used by Sealion viewer. You can use this to load reference genomes directly from GenBank files instead of manually creating JSON files.

Select GenBank File

Usage Example

// In your code:
const fileInput = document.getElementById('myFileInput');
fileInput.addEventListener('change', async (e) => {
  const file = e.target.files[0];
  const text = await file.text();
  
  // Parse GenBank file
  const refGenome = SealionUtils.parseGenBankFile(text);
  
  if (refGenome) {
    // Add to alignment
    alignment.addReferenceGenome(refGenome);
    console.log('Loaded reference:', refGenome.accession);
  }
});
